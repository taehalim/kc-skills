# 샘플 데이터 생성 규칙

## 공통 품질 기준

| 기준 | 확인할 내용 |
| --- | --- |
| 업무 적합성 | 각 기록이 화면 장식이 아니라 검색, 신청, 비교 또는 추적 행동에 사용되는가 |
| 다양성 | 정상 상태만 반복하지 않고 필터·정렬·예외를 확인할 차이가 있는가 |
| 일관성 | ID, 날짜, 상태, 수량, 금액과 참조 관계가 서로 맞는가 |
| 재현성 | 기준 날짜와 생성 규칙이 있어 다시 만들거나 테스트할 수 있는가 |
| 안전성 | 실제 개인정보, 회사 기밀, 저작권 자료, 자격증명과 실제 운영 URL이 없는가 |
| 설명 가능성 | 비전문가가 값을 보고 해당 업무 상황을 이해할 수 있는가 |

정상 흐름을 보여주는 데이터와 검색 결과 없음, 경계값, 중복, 권한 거부처럼 실제로 확인할 예외 데이터를 함께 준비한다. 저장 가능한 데이터와 의도적으로 실패시킬 입력은 분리한다.

## 가상 정보 표기

- 조직: `가상 조직 A`, `가상 연구소`
- 사람: `가상 사용자 01`, `가상 담당자 A`
- 이메일: `operator01@example.com`
- 전화번호가 필수가 아니면 생성하지 않는다.
- 실제 형식 검증이 필요하면 화면이나 데이터 설명에 `가상 정보`라고 명시하고 저장 범위를 최소화한다.
