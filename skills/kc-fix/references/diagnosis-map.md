# 진단 지도

| 계층 | 대표 증거 | 먼저 확인할 것 |
| --- | --- | --- |
| 브라우저·화면 | 클릭해도 반응 없음, 입력 검증이나 배치 문제 | 정확한 행동, 브라우저 콘솔, 보이는 상태 |
| 애플리케이션 | 요청 실패, 경로 또는 서버 오류 | 첫 번째 관련 애플리케이션 오류와 최근 변경 |
| 데이터·접근 | 쓰기 거절, 빈 결과, 잘못된 사용자 접근 | 스키마, 정책, 요청 주체, 저장된 행 |
| 환경 | 로컬에서는 되지만 공개 환경에서 실패, 설정 누락 | 환경변수 이름과 대상 환경. 값은 출력하지 않는다. |
| 빌드·의존성 | 설치 또는 빌드 실패 | 첫 실패, lockfile, 고정한 안정 버전 |
| 배포·공개 범위 | 이전 화면, 보호된 URL, 배포 실패 | 선택한 프로젝트, 최신 배포, 공개 접근 |
| 외부 API | 시간 초과, 사용량 한도, 인증 실패 | 제공자 상태, 키 존재 여부, 사용량. 키는 노출하지 않는다. |

관찰한 동작이 처음 기대와 달라지는 계층에서 시작한다. 상위 계층의 실패를 우회하려고 하위 계층을 다시 작성하지 않는다.
