# 예시 프로젝트

| 유형 | 프로젝트 | 이런 문제를 해결하고 싶을 때 | 설계 사례 |
| --- | --- | --- | --- |
| 정보 탐색형 | 반도체 공장 설비 알람·조치 사례 검색 | 준비된 업무 사례를 빠르게 검색하고 이해하고 싶음 | [상세 PRD](prd-information-discovery.md) |
| 신청·운영형 | 배터리 연구소 공용 시험장비 예약 | 한정된 공용 자원의 중복 예약과 운영 혼선을 줄이고 싶음 | [상세 PRD](prd-application-operations.md) |
| 비교·검증형 | 자동차 부품 구매팀 공급사 견적 비교 | 여러 입력의 차이와 누락을 한 화면에서 확인하고 싶음 | [상세 PRD](prd-input-processing.md) |
| 현황·추적형 | 전자제품 공장 품질문제 개선조치 추적 | 담당자, 기한, 상태와 지연 업무를 놓치지 않고 싶음 | [상세 PRD](prd-status-tracking.md) |

사용자에게는 처음부터 상세 PRD 전체를 제시하지 않는다. 먼저 네 제목과 한 줄 문제만 보여주고, 사용자가 고른 사례 하나에서 문제 구조와 설계 방식을 참고해 현재 프로젝트의 새 `PRD.md`를 작성한다.
