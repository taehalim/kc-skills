# 프로젝트 환경 원칙

실행 환경을 구성하거나 외부 서비스를 선택해야 할 때만 참고한다.

1. 사용자가 지정한 기술, 조직 표준과 제공된 프로젝트 기본값을 우선한다.
2. 지정이 없으면 요구사항을 충족하는 안정적인 구성 중 의존성과 운영 부담이 적은 것을 선택한다.
3. 데이터베이스, 서버, 인증과 외부 서비스는 핵심 흐름에 필요할 때만 추가한다.
4. 외부 서비스 사용이 제한되면 로컬 실행과 안전한 가상 데이터로 구성한다.
5. 외부 서비스 사용이 허용되면 승인된 공급자와 계정 범위 안에서 필요한 기능만 연결한다.
6. 비용, 데이터 위치, 보안, 운영 책임 또는 핵심 기능을 크게 바꾸는 선택은 사용자에게 확인한다.

선택 이유는 작업 환경과 연결해 짧게 설명한다.
